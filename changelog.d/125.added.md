The daemon builds a release's environment from `uv.lock` before it starts: a source with a lock and no `.venv` gets one of its own under the state directory, built as the release's user with uv's output in the release log, and the release is `building` meanwhile. `--build`, `--build-extra` and `--build-group` on `muructl deploy`, or the `build` table of a project or a declared release, say when and how; a Python the node lacks is downloaded first when the `[tools]` table allows it.
