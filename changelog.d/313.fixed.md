On Alpine and other musl-based systems, the runtime library `muructl` fetches or unpacks is now the musllinux wheel. Before, Python 3.11 to 3.13 were taken for glibc and given the manylinux wheel, whose extension cannot load on musl, and Python 3.14 and later found no wheel at all, because `platform.libc_ver()` reports musl's version as `1`.
