Added `muructl build`, which builds a project's environment from `uv.lock`, probes the interpreter and provides the runtime library, and made `muructl run` a build then a serve: a project with a lock and no `.venv` is built on the first run, an existing environment is used as it is and said to be behind the lock when it is, and a change to `uv.lock`, `.python-version` or `requires-python` under reload builds before the new release starts. The build mode is `when` in `[tool.muru.build]` or `muru.local.toml`, or `--build` on the command line.
