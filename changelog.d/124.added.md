Added version requests for the interpreter: `--python 3.13`, `python = "3.13"` in `[tool.muru]`, a `.python-version` file or `requires-python` name a Python that `muructl run` and `muructl deploy` resolve with uv, and every interpreter is probed before the host starts, so an unsupported one or one outside `requires-python` fails with a message naming both versions. `muructl release show` prints the resolved version and tag, and the daemon's `[tools]` table names uv, where managed interpreters go and whether they may be downloaded.
