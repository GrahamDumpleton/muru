Added `muructl requests`, which shows the requests in flight now as `muructl websockets` shows open sockets: counted by worker group, since the edge queues per group, as QUEUED and QUEUED-OLDEST, THREADS (busy of the group's threads) and THREAD-OLDEST, and LOOP and LOOP-OLDEST, the columns of the sides the release has; and with `--list` each request, the oldest first, with its age, state (queued or running), kind (`wsgi`, `wsgi streaming`, `asgi`, `asgi streaming`, `grpc`, `handoff` or `upstream`), worker, method and target, client and request id. Served by the daemon, a development run and `muructl serve`, with `--json` and an MCP tool beside `websockets`. The edge keeps the listing beside each request's access log record, spread over several maps so that a request's arrival and end never queue on one lock, and a busy worker's throughput measured the same with it. ([#379](https://github.com/muruhq/muru/issues/379))
