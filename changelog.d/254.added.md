Added `--json` to every `muructl` command that reports something: status, the lists, releases, rollouts, overlays, scaling, events, logs, metrics, WebSockets, and what deploy, rollback, drain, restart, maintenance and the other changes did. The output is the admin API's answer with its field names, streams print JSON lines, and a failure prints `{"error": ...}` with the same exit status; the JSON output reference lists each command's shape.
