Added `muructl mcp skill`, which prints, installs or checks a skill for coding agents that teaches the development loop under Muru: what releases and traffic are, what deploy, promote, rollback, drain and rollouts do, and what to check after each. The skill is embedded in `muructl` and versioned with it; `install` writes it to `.claude/skills/muru/SKILL.md` (or another directory with `--dir`), `status` says whether the project's copy is current, and the MCP server tells the agent when it is out of date.
