Added the daemon file's `[shutdown]` table: `on_sigterm` says whether SIGTERM detaches the daemon or shuts everything down, which it does by default as a container's main process so `docker stop` drains; `delay` keeps the edge accepting while connections close after their response, and `budget` bounds the whole shutdown, which `muructl daemon stop --shutdown` now runs as the same sequence, stopping every host at once and the edge last.
