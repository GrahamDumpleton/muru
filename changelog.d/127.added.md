The `muru` runtime library is provided by `muructl` itself and no longer has to be a dependency of the application: `muructl run` and the daemon put the copy matching their own version on the host's `PYTHONPATH`, fetching the wheel for the interpreter once into the user cache or the state directory. An environment that already has the matching `muru` is used as it is, so offline machines need no flag; `MURU_WHEEL_DIR` and `MURU_OFFLINE`, or `wheel_dir` and `offline` in the daemon's `[tools]` table, cover machines without network. `muructl runtime install` unpacks the library for an image.
