Added `muructl mcp serve`, a Model Context Protocol server that gives a coding agent the daemon's operations as tools: status, lists, releases, events, logs, worker stacks and the other debug views, metrics, deploy, promote, rollback, drain, rollouts, scaling, restarts, overlays, maintenance, apply and log levels, plus the user guide. Each tool runs the matching `muructl` command with `--json`; `--read-only` and `--allow` limit what the agent may change, and `--up` starts the daemon when none answers. The coding agents guide describes the development loop.
