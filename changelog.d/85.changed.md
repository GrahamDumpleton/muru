`muructl run` reloads on change by default in development mode, as `runserver` and `flask run` do: `--no-reload` turns it off for one run and `reload = false` in the project's run table or `muru.local.toml` for good. A `[tool.muru.run]` table in pyproject.toml (`[run]` in muru.toml) holds the settings only `muructl run` has, such as the port, HTTPS and its certificate, the extra names, the reload patterns, the access log and the dashboard, and `muru.local.toml` beside the project holds the same table for one machine; a flag wins over the local file, which wins over the project's table.\n
