# Vendored assets

Embedded in the binary; there is no build step.

- `htmx.min.js`: htmx 2.0.4 (https://htmx.org), Zero-Clause BSD, see
  `htmx.LICENSE`.
- `sse.js`: the htmx Server-Sent Events extension 2.2.3
  (https://github.com/bigskysoftware/htmx-extensions), Zero-Clause BSD,
  see `htmx-ext-sse.LICENSE`.
- `uPlot.iife.min.js` and `uPlot.min.css`: uPlot 1.6.32
  (https://github.com/leeoniya/uPlot), MIT, see `uPlot.LICENSE`.
- `charts.js`: Muru's own, drawing the history the gateway serves.
