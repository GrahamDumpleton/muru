# Security policy

Report security problems privately through GitHub security advisories for the
repository, not through public issues, discussions or pull requests. Include
the Muru version, how Muru is run, the platform and steps to reproduce.

You should receive an acknowledgement within seven days. Confirmed problems
are fixed in a new release, with credit to the reporter unless they prefer
otherwise, and announced through a security advisory.

Until 1.0, only the newest release receives security fixes.

The security model is described in the design specification,
[section 12](design/12-security-model.md).
